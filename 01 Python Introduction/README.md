# Introduction to Python

Python is a high-level, interpreted programming language known for its simplicity and readability. It was developed in 1991 by Guido van Rossum. This document summarizes the core concepts, features, and popular libraries of Python based on initial learning notes.

|--------------------|----------------------------------|

| **Developed In**   | 1991                             |
| **Type**           | High-Level Programming Language  |
| **Paradigm**       | Object-Oriented, Interpreted     |

## Key Notes:
- **Python** is an **interpreted** language, meaning it executes code line by line without needing a separate compilation step.
- It is **dynamically typed**, so you don't need to declare the data type of a variable explicitly.
- Parentheses are required for function calls, but optional for control flow statements (unlike PHP):
  ```python
  print("Hello, World!")  # Valid
  if True:                # No parentheses needed
      print("Hello")      # Indentation is crucial
  ```
