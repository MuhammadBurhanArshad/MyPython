## ➕ Arithmetic Operators

Arithmetic operators are used to perform mathematical operations like addition, subtraction, multiplication, etc.

| Operator | Name | Example | Description |
| :--- | :--- | :--- | :--- |
| `+` | Addition | `10 + 5` | Adds two operands |
| `-` | Subtraction | `10 - 5` | Subtracts the right operand from the left |
| `*` | Multiplication | `10 * 5` | Multiplies two operands |
| `/` | Division | `10 / 5` | Divides the left operand by the right (returns float) |
| `//` | Floor Division | `10 // 3` | Divides and returns the integer part (rounded down) |
| `%` | Modulus (Remainder) | `10 % 5` | Returns the remainder of the division |
| `**` | Exponentiation (Power) | `2 ** 3` | Raises the left operand to the power of the right |

### 💡 Examples Explained:
- **Addition (`+`)**: `10 + 5` results in `15`.
- **Subtraction (`-`)**: `10 - 5` results in `5`.
- **Multiplication (`*`)**: `10 * 5` results in `50`.
- **Division (`/`)**: `10 / 5` results in `2.0` (always returns a float in Python 3).
- **Floor Division (`//`)**: `10 // 3` results in `3` (it discards the decimal part).
- **Modulus (`%`)**: `10 % 5` results in `0` (since 5 divides 10 evenly).
- **Exponentiation (`**`)**: `2 ** 3` results in `8` (2 multiplied by itself 3 times).
